# 铃月与守灯人：十六姿态源图

这批透明 4×4 源图由 Codex 内置图像生成工具绘制，请求使用 Images 2.6。工具未返回具体模型标识。每格是一张单独绘制的姿势，旧八姿态素材保留在原处。

共用的绘图要求：以原角色设定和动作图为参考，延续像素风、服装、武器与朝向；每格一人，脚底对齐，武器和尾巴留出安全边；无文字、地面或背景。跑动图按脚步交替闭合循环；攻击图按起势、命中和收招排列，双连斩和回旋各标记两次命中姿势。

`sources.json` 记录原图校验值、参考图、选定顺序和命中姿势。突刺图的第 9 格剑尖超出等分线；切分沿实测透明间隙挪动该边界，保留完整剑尖。运行 `python SourceArt/image26/pack.py` 可重新生成 Unity 帧及动画曲线。需 Pillow、NumPy、SciPy。
